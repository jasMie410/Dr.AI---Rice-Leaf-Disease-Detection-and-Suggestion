# Dr.AI - Rice Leaf Diseas Detection and Suggestion

Hướng dẫn cài đặt và chạy dự án **﻿Dr.AI - Rice Leaf Diseas Detection and Suggestion
** với Node.js và Python.

## Yêu cầu hệ thống

- **Node.js** v18.20.2
- **Python** (phiên bản 3.x)
- **pip** (công cụ quản lý gói của Python)

## Các bước cài đặt

### 1. Clone dự án về
Đầu tiên, clone dự án từ GitHub về máy tính của bạn:

```bash
git clone https://github.com/username/Dr.AI---Rice-Leaf-Disease-Detection-and-Suggestion.git
cd Dr.AI---Rice-Leaf-Disease-Detection-and-Suggestion

Step1: Build .venv
Step2: .venv -> active
Step3: pip install -r requirement.txt
Step4: cd front-end -> npm install

Linux : B5 make run

Win: B5 python back-end/app.py -> cd front-end -> npm run dev
